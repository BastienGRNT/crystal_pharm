# L'espace des pharmacies — `app/pharmacy/`

Les outils d'un Tenant, utilisés par ses Managers. Une seule app, des modules :

- `host/` : l'app SvelteKit (le déployable), qui monte les modules ;
- `modules/` : un outil par module.

Chacun a son `CLAUDE.md`. Les règles Svelte communes : cf. racine, « Svelte ».
