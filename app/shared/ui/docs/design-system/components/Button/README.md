# Button

Bouton d'action (`<button class="cp-btn">`). Le bouton principal prend la couleur du module courant.

- **Défaut** : action principale de la page ou du formulaire. Un seul par zone.
- `cp-btn--secondary` : action alternative (« Exporter », « Réactiver »), fond blanc et filet.
- `cp-btn--danger` : action qui retire (« Désactiver », « Refuser »), texte rouge sur fond blanc.
- `cp-btn--ghost` : action discrète (« Annuler »).
- Tailles `--sm` (ligne de tableau), `--lg` (connexion). `cp-iconbtn` pour un bouton icône seul, avec `aria-label`.

Libellé au verbe à l'infinitif, icône Phosphor 16px optionnelle en premier.
