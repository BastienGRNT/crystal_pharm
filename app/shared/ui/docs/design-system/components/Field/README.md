# Field

Champ de formulaire : `<label class="cp-field">` avec `cp-field__label`, le contrôle (`cp-input`, `cp-select`), puis `cp-field__hint` ou `cp-field__error`.

Au focus, la bordure et le halo prennent la couleur du module. Erreur : `cp-field--invalid`, `aria-invalid` et `aria-describedby`. `cp-form` aligne les champs en grille.
