# Table

Tableau de données en carte (`cp-table-wrap` > `cp-table`) pour les listes d'employés.

- En-têtes en `caption` sur `surface-subtle`, lignes séparées par `line`, survol `surface-subtle`.
- Première colonne `cp-person` : avatar, nom en gras, email ou poste dessous.
- Actions alignées à droite dans `is-actions`, boutons `--sm`. Chiffres à droite avec `is-num`.
- Employé désactivé : `tr.is-inactive`. Colonnes secondaires masquables sur mobile avec `is-hide-sm`.
